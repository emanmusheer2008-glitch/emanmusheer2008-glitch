# Learning Guide: GitHub profile README

## What is it?

A special `README.md` that GitHub shows at the top of your profile page. It is the first thing a scholarship reviewer sees.

## How it works

GitHub shows it only if **all** of these are true (from GitHub's documentation):
1. A repository exists with **exactly** your username as its name: `emanmusheer2008-glitch`
2. The repository is **public**
3. It contains a `README.md` in the root folder

## How to publish it (about 3 minutes)

1. On GitHub, click **+** → **New repository**.
2. Repository name: `emanmusheer2008-glitch`. GitHub will say *"You found a secret!"*.
3. Choose **Public** and tick **Add a README file** → **Create repository**.
4. Click the pencil ✏️ on README.md, delete everything, paste the content of this folder's `README.md`.
5. Replace every `[BRACKETED]` placeholder with true information, or delete the line.
6. Click **Commit changes**.

## Design choices (and why)

| Choice | Reason |
|---|---|
| No visitor counters, streak stats or "top languages" cards | With few repositories they look empty. Reviewers value real projects more than decoration. |
| Status labels (in progress / in preparation) | Honest. It shows you know the difference between planned and finished work. |
| Only tools you have really used | Every listed skill can be questioned in an interview. |
| Short | Reviewers skim. Five sections are enough. |

## Rules for keeping it honest

- Add a skill only after you have used it in a project on this profile.
- Change "In progress" to a result only when the result is confirmed.
- Never add awards, ranks, affiliations or certificates you do not have.

## Also do this (profile settings)

- Add a clear profile photo, your name, and a one-line bio (e.g. "Student · AI Engineering & Data Science").
- **Pin** your best 4 repositories (profile → *Customize your pins*): TrafficFlowBench (once the repo is public, after the competition), Gulf Electricity Transition, OrbitFlame AI, Pop Calculator.
